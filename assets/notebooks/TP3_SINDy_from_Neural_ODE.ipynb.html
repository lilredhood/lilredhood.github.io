TP3 — Retrouver une loi de vieillissement à partir d'une Neural ODE¶

Objectif¶

Dans le TP précédent, on a appris une dynamique de vieillissement à partir de la tension mesurée :

$$ (SOC,T,I) \longrightarrow f_\theta \longrightarrow \left( \frac{dD_C}{dQ}, \frac{dD_R}{dQ} \right). $$

Le réseau neuronal constitue donc maintenant un modèle continu du champ de vieillissement.

Dans ce TP, on ne cherche plus à entraîner la Neural ODE.

On va au contraire l'utiliser comme un modèle déjà appris afin de retrouver une loi explicite et interprétable avec une approche de type SINDy :

$$ \boxed{ \text{Neural ODE apprise} \rightarrow \text{échantillonnage du champ} \rightarrow \text{bibliothèque de fonctions} \rightarrow \text{régression parcimonieuse} \rightarrow \text{loi explicite} } $$

On va :

  1. recharger les poids de la Neural ODE multi-véhicule ;
  2. interroger le réseau pour différents $(SOC,T,I)$ ;
  3. construire une bibliothèque de fonctions candidates ;
  4. comprendre la régression parcimonieuse utilisée par SINDy ;
  5. retrouver une loi compacte pour la capacité et la résistance ;
  6. jouer avec le seuil de parcimonie ;
  7. tester une bibliothèque volontairement trop riche ;
  8. supprimer volontairement une variable importante ;
  9. étudier un cas de mauvaise excitation ;
  10. comparer les trajectoires produites par la Neural ODE et par la loi identifiée.

Dans ce TP, on s'intéresse au vieillissement de cyclage. Le vieillissement calendaire est supposé connu et traité séparément.

1 — Pourquoi appliquer SINDy après une Neural ODE ?¶

Une approche directe consisterait à estimer une dérivée à partir d'une trajectoire potentiellement bruitée :

$$ D(Q) \longrightarrow \frac{dD}{dQ}. $$

Cette opération est sensible au bruit.

Ici, la Neural ODE apprise dans le TP précédent fournit déjà directement un champ continu :

$$ \boxed{ f_\theta(SOC,T,I) \approx \frac{dD}{dQ}. } $$

On utilise donc le réseau comme un surrogate continu et lissé, puis on cherche une expression analytique simple qui l'approxime.

L'idée de SINDy est de supposer que la dynamique peut être décrite avec seulement quelques termes parmi une bibliothèque plus large :

$$ \frac{dD}{dQ} = \Theta(SOC,T,I)\,\xi. $$

La matrice $\Theta$ contient les fonctions candidates et le vecteur $\xi$ leurs coefficients.

On cherche ensuite une solution parcimonieuse, c'est-à-dire avec peu de coefficients non nuls.

class AgeingNN(eqx.Module):
    mlp: eqx.nn.MLP

    def __init__(self, key):
        self.mlp = eqx.nn.MLP(
            in_size=3,
            out_size=2,
            width_size=16,
            depth=2,
            activation=jax.nn.tanh,
            key=key,
        )

    def __call__(
        self,
        soc,
        temp,
        current,
    ):
        x = jnp.array([
            soc,
            (temp - 25.0) / 20.0,
            jnp.abs(current) / 200.0,
        ])

        raw = self.mlp(x)

        return jax.nn.softplus(raw)

2.1 Interroger le champ appris¶

La sortie brute du réseau doit être remise à l'échelle :

$$ \frac{dD_C}{dQ} = s_C f_{\theta,C}, $$

$$ \frac{dD_R}{dQ} = s_R f_{\theta,R}. $$

On crée une fonction qui renvoie directement les deux vitesses physiques de vieillissement.

def ageing_rates_one(
    model,
    soc,
    temp,
    current,
):
    raw_rates = model(
        soc,
        temp,
        current,

    return jnp.array([

def regression_metrics(
    y_true,
    y_pred,
):
    rmse = np.sqrt(
        np.mean(
            (
                y_true
                - y_pred
            )**2
        )
    )

    nrmse = (
        rmse
        / np.std(y_true)
    )

    r2 = (
        1.0
        - np.sum(
            (
                y_true
                - y_pred
            )**2
        )
        / np.sum(
            (
                y_true
                - np.mean(y_true)
            )**2
        )
    )

    return rmse, nrmse, r2

6 — Le cœur de SINDy : STLSQ¶

Une stratégie classique de SINDy est STLSQ :

Sequentially Thresholded Least Squares.

Principe :

  1. résoudre une régression ;
  2. supprimer les coefficients dont la valeur absolue est inférieure à un seuil $\lambda$ ;
  3. refaire la régression avec les termes conservés ;
  4. répéter jusqu'à stabilisation.

Schématiquement :

$$ \xi^{(0)} = \arg\min_\xi \left\| \Theta\xi-y \right\|_2^2, $$

puis :

$$ |\xi_j|<\lambda \quad\Rightarrow\quad \xi_j=0. $$

Comme les vitesses de vieillissement sont petites, on multiplie temporairement la cible par un facteur numérique pour rendre le seuil plus facile à manipuler.

In [55]:
Y_SCALE = 1.0e5


def stlsq(
    Theta,
    y,
    threshold=0.05,
    ridge=1.0e-8,
    n_iter=20,
):
    # Version pédagogique de STLSQ

    y_scaled = (
        y * Y_SCALE
    )

    n_features = (
        Theta.shape[1]
    )

    A = (
        Theta.T @ Theta
        + ridge
        * np.eye(n_features)
    )

    b = (
        Theta.T @ y_scaled
    )

    xi = np.linalg.solve(
        A,
        b,
    )

    for _ in range(n_iter):
        active = (
            np.abs(xi)
            >= threshold
        )

        if not np.any(active):
            break

        xi_new = np.zeros_like(
            xi
        )

        xi_new[active] = (
            np.linalg.lstsq(
                Theta[:, active],
                y_scaled,
                rcond=None,
            )[0]
        )

        if np.allclose(
            xi,
            xi_new,
        ):
            xi = xi_new
            break

        xi = xi_new

    return xi / Y_SCALE

Dans un problème réel, on ne connaît pas la bonne structure.

On propose donc :

L'objectif de SINDy est de supprimer les termes inutiles.

8 — Test 2 : jouer avec le seuil de parcimonie¶

$$ \lambda. $$

On mesure pour plusieurs valeurs :

  • le nombre de coefficients non nuls ;
  • l'erreur sur des points jamais utilisés pour l'identification.

13 — Révélation de la loi synthétique du TP précédent¶

À regarder seulement après l'identification.

La loi utilisée pour construire les données synthétiques avait volontairement une structure affine.

Pour la capacité :

$$ \frac{dD_C}{dQ} = k_C \left( 1 + SOC + 0.5\widetilde T + 0.5\widetilde I \right). $$

Pour la résistance :

$$ \frac{dD_R}{dQ} = k_R \left( 1 + 0.5SOC + 0.5\widetilde T + \widetilde I \right). $$

Les constantes globales $k_C$ et $k_R$ dépendent de l'amplitude du vieillissement choisie dans le TP précédent.

Pour comparer seulement la forme de la loi, on divise les coefficients estimés par le coefficient constant.

Les rapports théoriques sont :

$$ [1,\;1,\;0.5,\;0.5] $$

pour la capacité, et :

$$ [1,\;0.5,\;0.5,\;1] $$

pour la résistance.

Conclusion¶

On est passé d'un modèle flexible mais peu interprétable :

$$ \boxed{ \frac{dD}{dQ} = f_\theta(SOC,T,I) } $$

à une loi compacte :

$$ \boxed{ \frac{dD}{dQ} \approx \Theta(SOC,T,I)\xi. } $$

La Neural ODE joue le rôle d'un modèle continu appris à partir des données, tandis que SINDy sert à extraire une structure analytique interprétable.
